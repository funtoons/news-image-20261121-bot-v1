Sum up 21 November's world news in one image: a one-page newspaper of Saturday 21 November 2026 — 10 main stories and 20 more, a dotted world map, and the day in numbers. Every story was verified against at least two sources (see RESEARCH.md). The program is pure Python standard library: it draws the page with an embedded 5x7 bitmap font and writes a 1024x1024 PNG with no network, no randomness and no clock, so two runs are byte-identical.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
